## 4. 가져오지 않는 것

v1 PR에 함께 들어 있었지만 요건이 아니라 v1 구현이다. v2로 옮기지 않는다.

- v1 화면 구조: 공연 상세 "판매정보" 탭, PC 요약 칸·모바일 블록 위치, 티켓 선택 시트의 회색 안내 박스, 체크아웃 하단 고정 바, 결제 화면 [유의사항]·[환불규정] 아코디언과 펼침 높이
