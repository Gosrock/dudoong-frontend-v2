# DuDoong-Front v2 — 스토리보드

> 근거: 백엔드 통합 기획서 F1~F11의 단계별 시퀀스 + Figma 와이어프레임. 화면마다 호출 API와 소유 Phase를 적는다.
> API ID는 [`api-contract.md`](./api-contract.md) §5, Phase는 [`plan.md`](./plan.md). Figma 노드는 [`figma-structure.md`](./figma-structure.md).

## H. 인증

```
[보호 화면 접근] → 토큰 쿠키 있음? ──아니오──▶ [/login?redirect=…]   (proxy.ts)
        │예                                         │ 카카오 OAuth (v1)
        ▼                                           ▼
   화면 렌더 → API 호출                        신규 판정? ──예──▶ [회원가입 오버레이]
        │                                           │
   AUTH_401_1 ──▶ 재발급(한 번만) ──성공──▶ 재시도   ▼
        │                    └─실패──▶ [/login/expired?redirect=…]
   GLOBAL_401_1 ──▶ [/login/expired?redirect=…]   원래 경로로 복귀

공개 화면: 서버 조회는 토큰을 붙이지 않는다. 클라이언트 조회에서 401이 오면 토큰 없이 다시 요청한다.
```

## 화면 → Phase

| 영역 | 화면 | Phase |
|---|---|---|
| 탐색 | 공연홈, 공연 리스트, 공연 상세, 호스트 홈 | P5a, P5b, P5c |
| 구매 | 티켓 선택, 체크아웃, 주문 완료 | P6, P7 |
| 티켓 | 티켓탭, 입장 QR, 선물 6화면 + 랜딩 7상태, 셀프 체크인 | P8, P8b, P8c |
| 마이 | 프로필, 주문내역·상세, 환불 계좌, 관심 호스트, 아카이빙, 알림함 | P9, P9b |
| 인증 | 로그인, 콜백, 회원가입 | P4a, P4b |
| 호스트 | 공연준비 홈, 호스트 만들기, 호스트 홈, 설정, 멤버 | P10a, P10b |
| 공연 준비 | 만들기 2단계, 체크리스트, 기본 정보, 상세 정보, 미리보기 | P11 |
| 티켓 관리 | 목록, 폼, 옵션 | P12 |
| 운영 | 대시보드, 주문 탭, 발급 티켓 탭, 환불, QR 체크인 | P13a, P13b |
