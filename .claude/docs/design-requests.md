# DuDoong v2 — 디자인·기획 요청

> 2026-10-15 작성, 같은 날 "GUI 화면" 파일(`1Cn4WOu6TDaSajbFIuH6fO`)을 읽고 갱신했다. 프론트 v2 계획을 백엔드 통합 기획서(2026-10-10), 백엔드 `dev` 코드, 와이어프레임 이미지 62장, GUI 화면과 대조하면서 나온 것이다.
> 노드 번호는 두 파일이 섞여 있다. `424:9918`처럼 와이어프레임 V0.9(`YQzHNU46AMT4iXlKuM4LnH`) 번호와, "GUI" 표시가 붙은 GUI 화면 파일 번호다. 화면 목록은 [`gui-screens.md`](./gui-screens.md)에 있다.

디자인 시스템 파일(토큰·컴포넌트)에 대한 정리 요청은 [`design-system.md`](./design-system.md) §5에 따로 있다.

이 문서는 네 부분이다.

1. **화면이 없는 것** — 프론트가 그릴 근거가 없다. 디자인이 필요하다. 19건(관객 7, 호스팅 12). GUI로 해결된 것은 4절에 따로 모았다.
2. **기획 질문** — 화면을 그리기 전에 정할 것. 18건(Q1~Q19 중 Q14는 해결돼 4절로 옮겼다).
3. **프론트가 정한 것(핸드오프)** — Figma와 서버가 다른 곳에서 프론트가 서버 기준으로 정한 것. 디자이너 메모 `103:2066`(GUI, "개발을 먼저 하고 … 의사결정한 것들 따로 정리하기, 핸드오프하고 피드백 받고 2차 수정")에 따라 이 표를 핸드오프 목록으로 쓴다(핸드오프의 원본 — `gui-screens.md` §4는 요약이다). 30건.
4. 해결된 것 — GUI 화면 파일로 답이 나온 항목.

각 항목의 "FE 잠정안"은 답이 오기 전까지 프론트가 그 방식으로 만든다는 뜻이다. 답이 오면 바꾼다.
